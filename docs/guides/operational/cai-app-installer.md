# Cài App Installer (chỉ Windows)

**Để làm gì?** App Installer chứa **winget** — công cụ giúp Claude cài phần mềm (Node.js, Java, VS Code...) cho bạn chỉ bằng một lệnh, thay vì bạn phải tự tải từng thứ.

Windows 11 và Windows 10 bản mới thường **đã có sẵn**. Claude chỉ nhờ bạn làm bước này khi máy chưa có.

## Các bước

1. Claude sẽ mở trang **App Installer** trên **Microsoft Store** — *đây là ứng dụng chính thức của Microsoft*.
   Nếu trang không tự mở, vào: https://apps.microsoft.com/detail/9nblggh4nns1
2. Bấm **Get** (hoặc **Update** nếu đã có bản cũ) — *để cài hoặc cập nhật winget*.
3. Đợi cài xong (1–2 phút).
4. **Tắt hẳn ứng dụng Claude rồi mở lại** — *để Claude nhận ra winget vừa cài*.
5. Gõ **"làm tiếp"** với Claude.

## Gặp vấn đề?

- **Không mở được Microsoft Store / bị chặn** (thường gặp ở máy công ty): báo Claude — Claude sẽ soạn sẵn tin nhắn để bạn nhờ bộ phận IT cài giúp.
