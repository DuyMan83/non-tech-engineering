# Skills

Nguồn chính của tất cả skill, chia theo công cụ:

| Thư mục   | Công cụ     | Trạng thái     |
|-----------|-------------|----------------|
| `claude/` | Claude Code | Đang phát triển |
| `codex/`  | Codex       | Sẽ bổ sung     |

Thư mục bắt đầu bằng `_` (ví dụ `_template`) là mẫu, không được cài.
